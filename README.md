# Ice Saw 2
Ice Saw 2 is a WIP all in one SSX Level Editor. This project was originally started as a Unity package and has evolved to be its own standalone program.

### How to Compile
###### On Linux
1. Install packages dotnet-sdk-8.0, and dotnet-runtime-8.0
2. Next to the Program.cs file, run `dotnet build .`
3. The executable will be in bin/Debug/net8.0/IceSaw2
